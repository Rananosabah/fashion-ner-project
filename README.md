Fashion Brand Entity Recognition and Retrieval from News Articles
This project presents a Natural Language Processing and Information Retrieval pipeline for detecting fashion brand entities from online news articles using weak supervision and DistilBERT. Fashion brands were automatically annotated through regex matching and converted into BIO-tagged sequences for Named Entity Recognition training. The fine-tuned DistilBERT model achieved strong performance in recognizing fashion brand entities from unseen text samples. In addition to the NER component, the project also implements a BM25-based retrieval system for ranking and searching fashion-related news articles. The work further includes evaluation, error analysis, and discussion of challenges related to ambiguous fashion brand names and noisy annotations.
